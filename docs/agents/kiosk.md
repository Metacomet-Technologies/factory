# Kiosk rules

React 19, strict TS, Vite+ (`vp`), Tailwind v4 CSS-first, shadcn on Base UI,
dark purple accent (one hue, AA contrast). **Theme follows the system**; never
force a default. Self-updates on build change; the reload guard gives up on stuck
requests after ~20 s. Visual and component rules live in
`docs/agents/kiosk-styleguide.md`; read it before changing any page.
